# AjayMart – Super Market Website

**AjayMart Super Market** is a creative, interactive static HTML/CSS/JavaScript supermarket website created and led by **Ajay Kumar Talari, Founder & CEO**.

## Included
- Modern supermarket home page
- Ajay Kumar Talari shown as the Founder & CEO
- Round CEO portrait on the home page
- Royal-style founder portrait on the About page
- 48+ supermarket products across 8 categories
- Local snack image so the Snacks category/product images work without relying on the broken remote image
- Product search, category filter and price sorting
- Wishlist interaction
- Persistent shopping cart using localStorage
- Checkout that creates an order
- Working login and registration
- CEO dashboard: total orders, delivered orders, pending orders, customer count and complete order details
- CEO can mark pending orders as delivered
- Customer dashboard: profile, masked payment card, order history, item details, totals and delivery status
- Contact details for AjayMart, Kurnool, Andhra Pradesh, India
- Responsive layout for desktop and mobile

## Run the project
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Install the **Live Server** extension if you do not already have it.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Important
This is a static front-end college project. Login, cards, orders and delivery tracking are simulated with browser `localStorage`. Passwords are not securely hashed and there is no real payment gateway or backend. This is suitable for demonstration, not for production authentication or real payments.
